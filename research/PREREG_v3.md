## 1. 연구 질문과 가설

주 질문: 같은 진입 규칙을 더 큰 시간봉에서 실행하면, 손절이 넓어져 비용이 1R에서 차지하는 비중이 줄고 거래당 순평균 R이 플러스로 바뀌는가?

- 근거: 5분봉에서는 최소 손절 0.10% → −0.46R, 0.40% → −0.18R로, 좁은 손절에서 비용이 거래당 약 0.35~0.4R을 차지했습니다.
- 귀무가설: 실행 시간봉을 바꿔도 비용 반영 순평균 R은 0 이하이다.
- 부 질문: 큰 시간봉 구간 + 15분 확인, 비용 기준 손절, 트랩 셋업, 데이터가 지지한 필터가 추가 개선을 주는가?
- 결과가 귀무가설을 기각하지 못하면 "이 방식은 규칙으로는 우위가 없다"를 정당한 결론으로 기록합니다.

**E1 구현 세부 (실행 전 고정)**

- 상위 시간봉 비율 유지: 5m 실행일 때 방향 15m·보조 1H(×3, ×12)였으므로, 실행 시간봉 k분이면 방향 3k분·보조 12k분으로 묶어 씁니다(예: 1H 실행 → 3H 방향, 12H 보조).
- 손절폭: 최소 0.40%는 유지. 최대 1.5%는 시간봉별 ATR(14) 중앙값 ÷ 5m ATR(14) 중앙값 비율로 비례 확대합니다(개발 구간에서 한 번 계산해 고정).
- 그 밖의 값(스윙 좌우 3봉, 20SMA, 기울기 기준, 구간 오차, 추격 금지 이격, T1 규칙, 수수료 0.05%·슬리피지 1틱)은 5m과 동일.
- 자금 관리 끔: 1R 고정, 일일 한도·목표·첫 승 절반·출금 없음, 코인당 동시 포지션 1개. 평가는 거래당 순수 R.
- 국면 정의: 일봉 20SMA 5봉 기울기 ±0.5% 초과 = 상승/하락, 아니면 횡보. 일봉 ATR(14)이 개발 구간 80백분위 초과면 고변동(우선 적용).
- 동률 처리: 검증 구간 평균 R 차이가 0.03R 이내인 시간봉이 여럿이면 자동 선택하지 않고 모두 보고한 뒤 송민제가 결정하고 변경 기록에 남깁니다.

- 경과 시간 고정 비교(예: 15m·30m에서 100분 SMA)는 보조 자료로만 보고하고 규칙 선택에 쓰지 않습니다.
- 지정가 진입은 이번 연구에서 제외하고 별도 연구로 둡니다(역선택으로 백테스트가 부풀려지기 쉬움).
- 표본이 하한(5장)보다 적어지는 단계는 성과와 관계없이 채택하지 않습니다.

**선택 절차 (E1~E8 전체를 하나의 전략 탐색으로 취급)**

1. 각 단계의 채택 규칙을 미리 고정합니다: 검증 구간 순평균 R이 가장 높고 표본 하한을 넘는 안을 고르며, 차이가 0.03R 이내면 더 단순한 안(조건이 적은 안)을 고릅니다.
2. E1~E8에서 실행한 모든 구성(시간봉, 필터 조합 포함)의 수와 결과를 기록부에 남기고, 최종 보고서에 "총 N개 구성 중 1개 선택"을 명시합니다.
3. 개발·검증 구간 성과는 증거로 인정하지 않습니다. 선택 과정에서 생긴 과최적화는 그 수치에 그대로 남아 있기 때문입니다. 성과로 보고하는 숫자는 최종 시험과 전진 시험 결과뿐입니다.
4. 최종 시험에는 선택된 구성 1개만 넣습니다. 비교 기준으로 현재 규칙(v1.4.1, 5m)도 같은 데이터에서 함께 계산하되, 이것은 선택이 아니라 기준선입니다.

| 위험 | 아래 '위험 기준의 수치' 충족 |

- 자금 관리(1R 고정, 일일 한도, 출금)는 채택된 신호에 따로 얹어 계좌 수익률과 최대 낙폭을 별도 계산합니다. 거래 빈도가 다른 시간봉끼리 일일 규칙 발동 차이가 비교를 왜곡하지 않게 하기 위함입니다.
- 운영 봇의 1회 위험은 우위가 확인될 때까지 0.5%이며(2026-11-16 23:50 적용), 5% 상한은 실제로 쓰지 않습니다.

**검정력과 표본 부족 판정**

- 검출할 효과 크기는 +0.15R, 유의수준 5%(단측), 검정력 80%로 고정합니다.
- 필요한 표본 수는 개발 구간 E1에서 측정한 거래당 R의 표준편차(σ)로 계산합니다: n ≈ (1.645 + 0.84)² × σ² ÷ 0.15². 예: σ = 1.2R이면 약 395건.
- 최종 시험 A·B 합계가 필요 표본 수에 못 미치면 성과와 관계없이 '표본 부족, 판정 보류'로 기록하고 전진 시험으로 표본을 채웁니다.

**위험 기준의 수치**

- 비교 조건: 같은 데이터, 같은 비용, 코인당 동시 포지션 1개.
- 최대 낙폭(R 단위)은 기준선(현재 규칙)의 1.2배 이하, 최대 연속 손실은 기준선 + 2회 이하.

## 6. 금지 사항

아래를 어기면 그 실험은 무효로 표시하고 기록부에 사유를 남깁니다.

1. 최종 시험 데이터를 규칙 선택 전에 보거나, 본 뒤 규칙을 고치는 것
2. 실패한 실험을 기록에서 지우거나, 가장 좋은 결과만 보고하는 것
3. 상한 8개를 넘기는 실험 (필요하면 사전 등록서 개정판을 먼저 커밋)
4. 거래 수를 채우려고 기준을 완화하는 것 (부족하면 '표본 부족으로 보류')
5. 단위가 다른 성과를 섞는 것 (R과 계좌 %, 다른 모델 버전의 Gemini 결과)
6. 운영 봇의 기존 장부를 실험 결과로 수정하는 것 (새 규칙은 그림자 장부로만 시작)

## 7. Gemini 부가 실험 (별도 장기)

Gemini 실험은 주 연구가 아니라, 큰 효과(+0.30R 이상)가 있는지만 보는 장기 그림자 실험입니다. 하루 1건 기준 +0.10R 차이 확인에는 약 3,140건(약 8.6년)이 필요하기 때문입니다.

- 역할 분리: 기계적 채점 8항목은 Python. Gemini는 차트 구조(이미지), 시간봉 충돌, 반대 시나리오만 판단.
- 거부 조건 우선: 상위 시간봉 역행 + 근거 부족, 진입 근거와 손절 위치 모순, 필수 데이터 누락 → PASS. 이벤트 거부 조건은 경제 일정 데이터를 붙인 뒤에만 켭니다.
- TAKE/PASS 기준: 첫 그림자 기록 30건은 기준 없이 수집만 하고, 그 뒤 기준을 변경 기록에 고정한 다음부터 평가합니다. 보류는 PASS로 취급합니다.
- PASS 후보도 끝까지 가상 추적: 같은 진입·손절·익절 규칙의 결과를 기록해 놓친 이익까지 잽니다.
- 안정성: 같은 후보를 3번 물어 다수결, 엇갈린 비율을 기록합니다.
- 버전 고정: 모델 `gemini-3.8-flash`, 프롬프트 버전·해시, 입력 해시, 설정값, 원본 응답, 호출 시각, 데이터 기준 시각을 모두 저장합니다. 모델이 바뀌면 새 실험으로 분리합니다.
- 시작 시점: 2장 최종 시험을 통과한 규칙이 생긴 뒤, 그 규칙의 후보에 붙입니다.
